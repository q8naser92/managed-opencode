# Windows 0.1.4 pilot publication

This package republishes the preserved Windows 0.1.4 pilot as v0.1.4-pilot.1.
The EXE/MSIs and their application payloads have not been rebuilt or modified.
The original archives remain preserved locally. The public archives have new
names and hashes because an organization-specific URL in RELEASE-NOTES.md was
replaced with a fictional example and its surrounding wording was generalized.
Checksums were regenerated and this publication note was added. No product code
or test results were changed by that redaction.

The binary product version remains 0.1.4. This is an unsigned Windows pilot
prerelease, not final production acceptance. There is no Mac GUI/PKG in this
release. See VERIFICATION.md in the deployment package for exact test scopes,
including outstanding native SAML/GUI, operational and organization-specific tests.

The companion source archive contains the archived Windows source and dependency
source ZIPs. A Git tag created for publication is a post-build source snapshot,
not the original build commit or a clean-build attestation. A clean independent
rebuild and complete license/software-composition audit remain outstanding.
